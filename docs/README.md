# VTE 문서 안내

| 문서 | 역할 |
|---|---|
| `../AGENTS.md` | 저장소 전체 에이전트 규칙, 동시 실행 모델 |
| `PROJECT_BRIEF.md` | 프로젝트 요약과 목표 |
| `DESIGN.md` | 시스템 설계 (아키텍처·모듈·데이터 모델) |
| `PLAN2.md` | v2 코딩 플랜 (마일스톤 M0~M6) |
| `SOURCE.MD` | 유사 프로젝트 조사 및 특징 검토 |
| `AI_WORKFLOW.md` | 빌드·검증 명령과 절차 |
| `SESSION.md` | 세션 인계 상태 (자주 갱신) |
| `TODO.md` | 우선순위 작업 목록 (체크박스) |
| `DECISIONS.md` | 설계 결정과 사유 |
| `TECH_NOTES.md` | 구현 세부 노트 |
| `KNOWN_ISSUES.md` | 알려진 제약·미해결 문제 |
| `BENCHMARK.md` | 실영상 벤치마크 결과 (M6부터) |
| `CHANGELOG.md` | 큰 이정표 기록 |

## 읽는 순서

처음 참여한 에이전트는 `PROJECT_BRIEF → DESIGN → PLAN2 → SESSION → TODO`
순으로 읽고 작업한다.
